# SipilCore

Situs: https://arifinsimo7-ui.github.io/SipilCore/

SipilCore menyediakan aplikasi desktop offline untuk teknik sipil:

- **AHSP Pro**: AHSP Cipta Karya, Bina Marga, dan SDA sesuai SE 47/SE/Dk/2026 – demo: `demo-ahsp.html`
- **RAB Rumah & Ruko**: 16 tipe rumah dan ruko – demo: `demo-rab-rumah.html`
- Bonus **Kalkulator Volume** di kedua aplikasi
